# 🐍 Python Practice Programs

A collection of beginner-friendly Python programs created to strengthen fundamental programming and problem-solving skills.

## 📌 About the Project

This repository contains simple Python programs covering important programming concepts such as loops, conditional statements, strings, lists, user input, and basic algorithms.

These exercises are useful for building a strong foundation in Python and preparing for **SDET, QA Automation, and Python coding interviews**.

## 📂 Programs Included

### 1. 🔢 Factorial
Calculates the factorial of a number entered by the user.

**Concepts:**  
- Loops
- User input
- Arithmetic operations

### 2. 🔄 Palindrome Checker
Checks whether a given word or string reads the same forwards and backwards.

**Concepts:**  
- Strings
- String slicing
- Conditional statements

### 3. 🔢 Fibonacci Series
Generates the Fibonacci series for the number of terms specified by the user.

**Concepts:**  
- Loops
- Variables
- Mathematical logic

### 4. 🧹 Remove Duplicates
Removes duplicate values from a list while keeping the original order.

**Concepts:**  
- Lists
- Loops
- Conditional statements
- List manipulation
